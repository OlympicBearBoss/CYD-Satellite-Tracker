# CYD Satellite Tracker — iPad app

Персональная версия приложения для iPad на SwiftUI. Интерфейс проекта рассчитан на запуск и дальнейшую доработку непосредственно на iPad через Apple Swift Playgrounds.

## Текущий статус

**Версия 0.1 — UI prototype**

Реализованы:
- Space Dark оформление с голубыми акцентами;
- русский и английский интерфейс;
- вкладки «Обзор», «Спутники», «Радар», «Ротатор», «Настройки»;
- демонстрационная карточка МКС;
- демонстрационный экран орбитальной обстановки;
- компасно-радарная схема;
- демонстрационные ползунки азимута 0–360° и угла места 0–90°.

Пока не реализованы: реальная загрузка TLE/SGP4, GPS/компас, авторизация через Cloudflare, синхронизация устройств, команды ротатору и push-уведомления. Ползунки не управляют моторами.

## Запуск на iPad через Swift Playgrounds

1. Установите Swift Playgrounds из App Store на iPad.
2. Откройте приложение и создайте новый проект типа App.
3. В созданном проекте откройте ContentView.swift.
4. Замените его содержимое кодом из apple-app/ContentView.swift этого репозитория.
5. В проекте найдите файл приложения с @main (обычно MyApp.swift). Замените его кодом из apple-app/CYDSatelliteTrackerApp.swift либо оставьте существующий @main и не добавляйте второй.
6. Нажмите Run ▶.

Если Playgrounds не позволяет открыть файлы напрямую из GitHub, откройте каждый файл на GitHub, выберите Raw, скопируйте содержимое и вставьте его в соответствующий файл Swift Playgrounds.

- README.md — инструкция запуска и статус разработки.

## План интеграции

1. Подключить безопасную авторизацию к существующему API CYD Satellite Tracker.
2. Реализовать профиль и список привязанных устройств.
3. Получать свежие орбитальные элементы из серверного источника и рассчитывать положение спутников.
4. Подключить CoreLocation и CoreMotion с запросом разрешений только по действию пользователя.
5. Добавить телеметрию и очередь команд для ESP32; сервер должен проверять владельца устройства.
6. Включить управление ротатором только после подтверждения онлайн-связи, состояния устройства и защитных ограничений.

## Безопасность

Не храните пароль, токен устройства или секреты API в исходном коде. Устройство должно получать команды только после серверной проверки авторизации и принадлежности аккаунту. Реальное управление моторами не активировать до завершения проверки прошивки, концевиков и аварийной остановки.
