# Архитектура CYD Satellite Tracker

## 1. Контроллер и подсистемы

ESP32-2432S028 / CYD 2.8 — локальный контроллер, который выполняет:
- получение координат и времени от GPS NEO-6M;
- опрос датчиков через единый I²C sensor service;
- расчёт положения спутников и целевых углов AZ/EL;
- локальную проверку ограничений и блокировок;
- Wi-Fi API, телеметрию и интерфейс оператора.

### Подтверждённая распиновка CYD

| Сигнал | GPIO ESP32 |
|---|---:|
| AZ STEP | 4 |
| AZ DIR | 16 |
| EL STEP | 17 |
| EL DIR | 26 |
| GPS UART2 RX (TX GPS NEO-6M) | 34 |
| I²C SDA (HMC5883L / ADXL345) | 27 |
| I²C SCL (HMC5883L / ADXL345) | 22 |
| TFT backlight | 21 |

GPIO34 — входной-only; он используется только для приёма UART GPS. GPS RX не подключается и прошивкой не используется. Не назначать GPIO34 на STEP, DIR или другие выходы.

Подтверждённые датчики на текущем этапе:
- QMC5883P — магнитометр, I²C 0x2C; проверен непрерывный опрос в тесте V6;
- ADXL345 — акселерометр, I²C 0x53; проверено чтение идентификатора DEVID=0xE5, поток измерений ещё требует проверки;
- GPS NEO-6M — UART2 RX GPIO34; живой GPS fix проверяется отдельно.

Планируемые, но ещё не введённые в эксплуатацию узлы:
- датчики положения осей AZ/EL;
- концевые выключатели через входной модуль;
- два шаговых двигателя US-17HS4401S с драйверами HR4988.

## 2. Потоки данных

1. GPS и датчики -> sensor service -> read-only telemetry snapshot.
2. Орбитальные данные + координаты станции + UTC -> расчёт целевых AZ/EL.
3. Целевые углы -> safety manager -> motion controller (только после проверки всех блокировок).
4. Телеметрия -> локальный HTTP API/WebSocket -> веб- и мобильные клиенты.

Клиенты не управляют GPIO и не обходят локальные ограничения контроллера.

## 3. Датчики и достоверность

- I²C SDA GPIO27, SCL GPIO22, 100 кГц, логика 3.3 В.
- QMC5883P инициализируется строго в порядке: 0x0B <- 0x01, затем 0x0A <- 0x01, затем 0x09 <- 0x1D.
- Магнитный азимут нельзя считать достоверным до установки датчика на окончательную конструкцию, калибровки и проверки компенсации наклона по акселерометру.
- GPS course-over-ground не используется как направление неподвижной антенны.
- Целевые углы спутника не являются разрешением на движение: фактическое положение осей должно подтверждаться установленными датчиками положения.

## 4. Движение и безопасность

- Драйверы HR4988 остаются заблокированными до проверки конкретных плат драйверов, полярности ENABLE, ограничения тока и проводки.
- Аппаратная E-stop цепь должна независимо отключать питание двигателей/разрешение драйверов.
- Концевики блокируют движение дальше в сторону активного предела, но допускают контролируемый отход.
- Команды движения ограничены диапазонами и коротким временем действия (dead-man lease).
- Локальный watchdog останавливает движение при потере команд, связи или достоверной обратной связи.
- Ошибка датчика, устаревшие данные угла или потеря GPS не должны приводить к самопроизвольному движению.
- На этапе интеграции датчиков STEP остаётся LOW, а ENABLE заблокирован. Автоматический homing и tracking motion не выполняются.

## 5. Состояние реализации

Прошивка переведена на HMC5883L + ADXL345: реализованы проверка идентификаторов, настройка регистров, чтение XYZ и предварительная компенсация наклона. Физическая проверка обоих датчиков на собранной плате ещё не выполнена. Основная прошивка содержит путь приёма GPS и интерфейс/сетевые функции; полная интеграция всех датчиков и безопасного управления осями остаётся следующим этапом.

Подробный контракт телеметрии, порядок запуска и план интеграции: [FIRMWARE_SENSOR_INTEGRATION.md](FIRMWARE_SENSOR_INTEGRATION.md).


## Датчики положения осей AS5600

Установлены два независимых канала AS5600 без I²C-мультиплексора. AZ подключён к I²C0 (SDA GPIO27, SCL GPIO22) совместно с QMC5883P/ADXL345 на отдельном адресе 0x36. EL подключён к I²C1 (SDA GPIO18, SCL GPIO19), адрес 0x36. GPIO18/19 — линии SD-интерфейса CYD; SD-карта в этой конфигурации не используется. Опрос — 100 мс. Прошивка читает STATUS и 12-битный RAW ANGLE, проверяет флаг MD (магнит обнаружен). Ноль AZ сохраняется при наведении на истинный север, ноль EL — при горизонтальном положении оси. Команда локального API calibrate_zero сохраняет нулевые значения в NVS. До калибровки данные считаются сырым углом датчика, а не истинным азимутом/углом места. Двигатели остаются заблокированными.
