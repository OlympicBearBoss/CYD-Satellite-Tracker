# Архитектура

1. CYD ESP32 — локальный контроллер, Wi-Fi AP или STA, safety manager и API.
2. TMC2209 — управление осями AZ и EL.
3. Датчики угла — обратная связь положения.
4. GPS — координаты и время станции.
5. Flutter-клиент — iOS, iPadOS и Android.
6. Web UI — интерфейс оператора и публичная документация.

## Потоки данных
- Команды: клиент → HTTP API → проверка диапазонов и блокировок → motion controller.
- Телеметрия: датчики → controller → WebSocket → клиенты.
- Потеря связи: локальный watchdog останавливает движение независимо от клиента.

## Безопасность
Аппаратная E-stop цепь должна отключать разрешение драйверов независимо от Wi-Fi и интерфейса. Концевики блокируют движение в сторону предела, но разрешают отход от него.
