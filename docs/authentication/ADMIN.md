# Администрирование CYD Satellite Tracker

## Возможности
Админ-панель: список аккаунтов, поиск и фильтр, блокировка и разблокировка, роли user/admin, удаление, завершение сессий, список привязанных устройств и журнал последних 100 административных операций.

## Первый администратор — только вручную
1. Создайте Cloudflare D1 с именем cyd-satellite-tracker-auth.
2. В настройках Cloudflare Pages добавьте D1 binding с переменной DB и выберите эту базу.
3. Примените migrations/0001_auth.sql, затем migrations/0002_admin.sql через D1 Console (или Wrangler после настройки реального database_id в локальном конфиге).
4. Зарегистрируйте обычный аккаунт на сайте.
5. В Cloudflare D1 Console выполните SQL, заменив email на адрес владельца:
   UPDATE users SET role='admin', status='active', updated_at=unixepoch() WHERE email='owner@example.com';
6. Убедитесь, что изменена ровно одна строка, выйдите из аккаунта и войдите снова. Пункт «Администрирование» появится в меню профиля.

Никогда не назначайте администратора через публичную регистрацию. Доступ к API проверяется на сервере по роли в D1 при каждом запросе.

## API
GET /api/admin/users — аккаунты, устройства, журнал (только admin).
POST /api/admin/action — действия block, unblock, role, sessions, delete (только admin).

При блокировке все сессии пользователя удаляются. Удаление каскадно удаляет identities, sessions и device_links. Последнего администратора нельзя заблокировать, понизить или удалить.

## Перед production
Публичная авторизация не готова к запуску, пока не настроены D1 binding и миграции. До открытия регистрации добавьте подтверждение email, сброс пароля, rate limiting/Turnstile, мониторинг и резервное копирование D1. Сначала проверяйте действия на staging.
