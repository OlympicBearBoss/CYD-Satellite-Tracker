# Привязка CYD ESP32 к аккаунту

## Как привязать устройство

1. Войдите на сайт под своим аккаунтом.
2. Откройте меню аккаунта → **Профиль и устройства** → **Мои устройства**.
3. Укажите название устройства и нажмите **Создать код привязки**.
4. В течение 10 минут передайте восьмизначный код прошивке ESP32.
5. Прошивка отправляет POST-запрос на `/api/devices/claim`:

```http
POST /api/devices/claim
Content-Type: application/json

{"code":"12345678","device_name":"CYD Rotator"}
```

Успешный ответ содержит `device_id` и `device_token`. Токен является секретом устройства: храните его в NVS/Preferences ESP32 и не выводите в Serial Monitor или интерфейс сайта. Код одноразовый, а токен показывается только при привязке.

## Проверка связи

Устройство отправляет heartbeat раз в 60 секунд:

```http
POST /api/devices/heartbeat
Authorization: Bearer DEVICE_TOKEN
```

Ответ `{"ok":true,"server_time":...}` подтверждает, что токен действителен. Поле `last_seen_at` обновляется автоматически.

Если устройство отозвано пользователем или администратором, heartbeat возвращает HTTP 401. Для повторной привязки создайте новый код и получите новый токен.

## API аккаунта

- `GET /api/account/profile` — текущий профиль.
- `POST /api/account/profile` — обновить `display_name` и `avatar_url` (только HTTPS).
- `GET /api/devices` — только устройства текущего пользователя.
- `POST /api/devices` — создать одноразовый код привязки (10 минут).
- `DELETE /api/devices?id=DEVICE_ID` — отключить только собственное устройство.
- `POST /api/devices/claim` — обменять код на токен устройства.
- `POST /api/devices/heartbeat` — аутентифицированная проверка связи.

Сервер проверяет сессию и владельца на пользовательских маршрутах. Администратор может просматривать все устройства и отзывать их через админ-панель.
