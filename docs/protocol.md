# Черновик локального Wi-Fi API

Базовый адрес: `http://cyd.local` (при реализации mDNS) либо IP-адрес контроллера.

## HTTP
- `GET /api/v1/status` — состояние связи, углы, GPS, концевики и ошибки.
- `GET /api/v1/config` — диапазоны и параметры конфигурации.
- `POST /api/v1/motion/jog` — кратковременное движение оси.
- `POST /api/v1/motion/stop` — программная остановка.
- `POST /api/v1/track/start` — запрос сопровождения.
- `POST /api/v1/track/stop` — остановка сопровождения.

## WebSocket
- `/ws` — телеметрия и события состояния.

## Требования
Команды движения должны иметь ограниченный срок действия (dead-man/lease), проверку диапазона, концевиков и watchdog. Сетевой API не заменяет аппаратный E-stop.
