# CYD Satellite Tracker firmware v2026.11.17.97

**Status:** CI candidate passed; awaiting on-device verification before stable release.  
**Base:** current `main` after release-management merge.  
**Purpose:** add persistent Russian, English, and Simplified Chinese language selection to the CYD display UI.

## Changes

- Added U8g2-based UTF-8 text rendering for Latin, Cyrillic, and Simplified Chinese glyphs.
- Added a translation table for fixed UI labels and common status messages.
- Added RU / EN / ZH selection controls to the System screen.
- Saved the selected language in ESP32 Preferences (`uilang`); Russian remains the default on a fresh device.
- Routed existing TFT text drawing through the multilingual renderer while preserving existing screen geometry and touch coordinates.
- Kept the current main-branch hardware profile, QMC5883P + ADXL345 SensorSuite, axis encoder support, Wi-Fi configuration, local API, and satellite/orbit code as the base.
- Did not import the experimental branch's provisional BoardConfig or pin assignments.
- Motor drivers remain locked; this change does not enable motor movement.

## Known limitations

- Some dynamically generated text, satellite names, and data strings may remain untranslated until they are added to the translation table.
- This candidate has passed CI but is not hardware-tested. Do not treat it as a stable release until the user verifies it on the CYD.
- No automatic motor enable or movement is introduced.
