# CYD Satellite Tracker firmware v2026.11.17.98

**Status:** CI candidate; hardware verification pending.  
**Base:** V97 multilingual firmware candidate on the current project hardware profile.  
**Firmware source commit:** [15512218793bec8d6888b29959fd392802a46026](https://github.com/OlympicBearBoss/CYD-Satellite-Tracker/commit/15512218793bec8d6888b29959fd392802a46026).

## Changes

- Expanded the startup initialization screen to report the QMC5883P compass, AS5600 azimuth encoder, AS5600 elevation encoder, ADXL345 tilt sensor, GPS receiver, and display/ESP32 status.
- Kept the HR4988 motor drivers locked; the initialization screen explicitly reports that motors remain disabled.
- Replaced the fixed dashboard compass pointer with a live pointer driven by the tilt-compensated QMC5883P magnetic heading.
- Refreshes only the compass hub at 250 ms intervals, preserving the radar artwork and avoiding a full-screen redraw.
- Updated the Wi-Fi keyboard to black keys with white legends and a cyan pressed-key highlight.
- Added visible Cyrillic key legends for Russian layout, including uppercase characters; the keyboard defaults to RU when the display language is Russian and EN otherwise.
- Corrected the second keyboard row hitbox so its spacing matches the drawn key spacing (24 px), preventing adjacent-key misregistration.
- Kept the numeric keypad, symbols page, Wi-Fi credential persistence, and existing touch calibration flow.

## Validation

- Source-level checks: passed for the intended initialization rows, live compass refresh, Russian key legends, black/white keyboard styling, and corrected second-row hitbox.
- PlatformIO firmware build: **passed** (GitHub Actions run [44033285954](https://github.com/OlympicBearBoss/CYD-Satellite-Tracker/actions/runs/44033285954)); all build, full-flash packaging, and artifact upload steps succeeded.
- V97 has been flashed to the user's CYD (reported by user); V98 has not yet been flashed or verified on hardware.
- Compass direction, AS5600 readings, Cyrillic rendering, and keyboard touch accuracy: pending on-device verification.

## Known limitations and safety

- The displayed compass heading is magnetic north; it is not yet corrected for local magnetic declination or hard-/soft-iron calibration.
- A valid tilt-compensated heading requires valid QMC5883P and ADXL345 readings.
- AS5600 sensors report valid only when their status register and magnet-detected flag are good.
- HR4988 drivers remain locked. Do not enable motor movement until driver ENABLE polarity, limit switches, mechanical travel, and emergency stop are verified.
