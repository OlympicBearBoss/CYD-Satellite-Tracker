# CYD Satellite Tracker firmware v2026.11.17.99

**Status:** CI candidate; hardware verification pending.  
**Base:** V98 sensor/UI candidate.  
**Purpose:** Correct the hardware profile to match the user's actual schematic. No AS5600 devices are installed or present in the approved hardware configuration.

## Changes

- Removed all AS5600 support from firmware calculations, startup detection, I²C polling, telemetry, and the local web control page.
- Removed the dual-axis encoder driver, AS5600 pin definitions, and AS5600 device address.
- Removed zero-calibration commands and stored offsets that depended on nonexistent shaft encoders.
- The azimuth heading continues to be calculated from the QMC5883P magnetometer, with tilt compensation from the ADXL345.
- The elevation/tilt indication continues to come from the ADXL345; it is not represented as an independent shaft encoder.
- The initialization screen now reports the actual installed sensor modules: QMC5883P compass and ADXL345 tilt sensor.
- The local web status page now displays QMC5883P magnetic heading and ADXL345 roll/pitch instead of nonexistent axis encoders.
- HR4988 motor drivers remain locked; no motor movement or enable logic was added.

## Validation

- Source audit: pending final residual-reference check.
- PlatformIO build: pending GitHub Actions.
- Hardware verification: pending user test.
- Compass calibration and magnetic interference correction are not included in this change. A successful build will not by itself establish accurate north/azimuth.

## Safety

Do not enable motors until the actual mechanical stops, limit switches, driver ENABLE wiring, and emergency-stop circuit have been verified.
