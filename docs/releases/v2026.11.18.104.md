## Новые функции

- Главная страница показывает реальные магнитный азимут QMC5883P, наклон ADXL345 (PITCH) и координаты GPS NEO-6M в одном блоке.
- Тест двигателей перенесён с отдельной страницы телеметрии на главную, чтобы запуск и остановка были доступны сразу.
- GPS API передаёт возраст последнего GPS-измерения в миллисекундах (gps_age_ms).

## Исправления

- Исправлена причина пустых показаний на главной: обработчик каждого обновления сбрасывал KPI азимута и угла в «—» и не заполнял их показаниями датчиков.
- Показания QMC5883P и ADXL345 отображаются только при наличии свежих валидных данных; ADXL345 подписан как наклон датчика, а не энкодер оси.
- Временный одиночный сбой локального Wi-Fi запроса больше не сбрасывает весь экран датчиков; связь признаётся потерянной после трёх последовательных неудачных запросов.
- Опрос локального API выполняется раз в 2 секунды без параллельных запросов.

## Изменения интерфейса

- На главной рядом с магнитным азимутом и наклоном отображаются GPS-координаты, статус FIX и количество спутников.
- Тест двигателей виден на главной странице; доступны подтверждённый запуск и программная остановка, состояние этапа и число импульсов.
- Сохранены локальный HTTP API и прямое подключение по Wi-Fi; облачная привязка не добавляется.

## Аппаратная часть и безопасность

- Распиновка без изменений: AZ DIR GPIO16, AZ STEP GPIO4, EL STEP GPIO17, EL DIR GPIO26.
- Используются только подтверждённые датчики: GPS NEO-6M, QMC5883P и ADXL345. AS5600 и дополнительные энкодеры не используются.
- Магнитный азимут не является истинным севером без калибровки и поправки магнитного склонения.
- ADXL345 измеряет наклон самого датчика, а не абсолютный угол оси антенны.
- Моторный тест: 300 импульсов в каждую сторону по AZ и EL с плавным разгоном/торможением. Он не проверяет концевики и не является аппаратным аварийным STOP.
- Ротатор не собран; запускать тест только при свободных валах и возможности немедленно отключить питание. Автоматическое наведение остаётся заблокированным.
