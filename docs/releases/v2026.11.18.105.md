## Новые функции

- Компас CYD использует QMC5883P как источник магнитного курса; числовой азимут нормализуется в диапазон 0.0–359.9° (360° не выдаётся).
- На главном экране CYD компасная шкала и стороны света вращаются под неподвижным красным указателем, который всегда показывает север.
- В центре шкалы CYD показывается числовой курс в градусах.
- На сайте при подключённом CYD компас использует только курс QMC5883P из локального API, а не компас телефона или планшета.
- На сайте вращаются роза компаса, кардинальные отметки и радарная плоскость; красный треугольник остаётся неподвижным и указывает на север.
- Сайт обновляет локальную телеметрию компаса каждые 250 мс, чтобы поворот отображался плавнее.

## Исправления

- Значение курса в JSON API дополнительно нормализуется в диапазон 0–менее 360°.
- Округление для отображения не позволяет показать 360°: переход через север отображается как 0°.
- При подключённом CYD события ориентации браузера не перезаписывают показания QMC5883P.

## Аппаратная часть и безопасность

- Используются только имеющиеся датчики: QMC5883P (магнитометр) и ADXL345 (наклон для компенсации наклона). GPS NEO-6M остаётся источником координат.
- Распиновка и I²C не изменены: SDA GPIO27, SCL GPIO22, QMC5883P 0x2C, ADXL345 0x53.
- AS5600 и любые дополнительные энкодеры не добавлялись.
- Это магнитный курс, а не истинный географический север. Калибровка hard-iron/soft-iron и поправка магнитного склонения пока не реализованы.
- Правильное направление N зависит от ориентации установки платы QMC5883P. Программная формула использует текущую принятую ориентацию +X вперёд, +Y вправо, +Z вверх; физическую ориентацию нужно подтвердить тестом поворота на месте.
- Автоматическое движение двигателей не включается. Моторный тест и блокировки остаются без изменений.
