# Firmware V106 — 2026-11-18

## Compass and sensor refresh

- QMC5883P and sensor service polling increased from 4 Hz to 20 Hz (50 ms cadence), subject to the sensor's configured output data rate.
- Heading validity no longer depends on ADXL345 tilt data. Tilt compensation remains active when tilt data is valid; otherwise the compass uses the horizontal X/Y magnetic field.
- Magnetometer samples are accepted only when QMC5883P reports fresh data without overflow.
- CYD compass is rendered into a 16-bit off-screen sprite and transferred as one frame to eliminate visible blinking.
- Compass redraw cadence increased to 20 Hz; fixed red north pointer retained.
- Website local status polling increased to 10 Hz; transitions shortened and cardinal labels remain centered while rotating.

## Hardware and safety

- Only existing QMC5883P (0x2C) and ADXL345 (0x53) are used.
- No AS5600, shaft encoders, new wiring, or I2C buses.
- Motor test, motor lock, GPIO assignments, and local Wi-Fi API command protocol are unchanged.
- Heading remains magnetic, not true north. Hard-/soft-iron calibration and magnetic declination correction are not implemented. The fallback without tilt compensation assumes the sensor board is approximately level.
