## Новые функции

- Добавлена отдельная страница **SYSTEM → MAG TEST** для диагностики QMC5883P.
- Страница показывает сырые X/Y/Z, необработанный угол XY и текущий статус датчика.
- Во время открытой страницы собираются min/max по X/Y/Z; диапазон сбрасывается при повторном входе.
- Расчёт RAW XY не использует ADXL345, roll/pitch или компенсацию наклона. Это позволяет вращать отдельно подключённый модуль QMC5883P, не поворачивая плату CYD.
- В Serial Monitor 115200 бод добавлена отдельная строка `[QMC-RAW]` с X/Y/Z и необработанным углом XY каждую секунду.

## Как проверить

1. Подключить модуль QMC5883P к CYD штатными проводами I²C.
2. Открыть **SYSTEM → MAG TEST**.
3. Не отключая модуль, вращать только сам модуль; плата CYD остаётся неподвижной.
4. Следить за RAW X/Y/Z и RAW XY ANGLE. Дать показаниям стабилизироваться в каждом положении.
5. Для анализа прислать четыре строки `[QMC-RAW]` из Serial Monitor при четырёх положениях модуля (примерно 0°, 90°, 180°, 270°).

RAW XY ANGLE — диагностическое направление по текущим X/Y, а не откалибренный компасный азимут. Не применять эти значения для управления антенной.

## Аппаратная часть и безопасность

- Сохранены QMC5883P 0x2C и ADXL345 0x53 на I2C0 SDA GPIO27 / SCL GPIO22, 100 кГц.
- Поддержка AS5600 не добавляется; распиновка не меняется.
- HR4988, STEP/DIR и логика моторного теста не изменяются.
- Неизвестный ENABLE не используется; автоматическое движение двигателей остаётся заблокированным.
- Калибровочные коэффициенты hard-/soft-iron не рассчитываются и не применяются автоматически.

## Ограничения

- Измерения RAW XY не компенсируют наклон, ориентацию монтажной платы и магнитные помехи.
- Изменение угла при отдельном вращении модуля проверяет сам QMC5883P и его сырые оси, но не подтверждает правильную ориентацию компаса относительно CYD.
- Успешная CI-сборка не заменяет аппаратную проверку.
