# Каталог спутников и расчёт положения

Веб-интерфейс получает открытые GP/TLE-орбитальные элементы CelesTrak (группы `stations`, `weather`, `amateur`). Для расчёта топоцентрических углов используется открытая библиотека satellite.js.

## Поток данных

1. Браузер запрашивает GP JSON у CelesTrak.
2. Пользователь выбирает объект по названию/NORAD ID.
3. Орбитальные элементы преобразуются в SGP4-объект.
4. По текущему UTC и введённым координатам станции рассчитываются азимут, угол места и наклонная дальность.
5. Углы можно перенести в демонстрационные ползунки управления. Реальные команды ESP32/двигателям не отправляются.

## Источники

- [CelesTrak GP data](https://celestrak.org/NORAD/documentation/gp-data-formats.php)
- [CelesTrak query interface](https://celestrak.org/NORAD/elements/)
- [satellite.js](https://github.com/shashwatak/satellite-js)

## Ограничения и безопасность

- Требуется интернет и доступ браузера к CelesTrak; при сетевых/CORS ограничениях обновление не сработает.
- Эпоха TLE/GP указывается отдельно. Чем старее элементы, тем менее точен прогноз; особенно для низких орбит.
- Для азимута/угла места обязательно задать широту и долготу наземной станции. Высота станции в текущей веб-демонстрации принята равной 0 км.
- Текущая версия считает положение объекта, но ещё не строит расписание пролётов и не фильтрует видимые проходы по маске горизонта.
- Перенос углов в интерфейс меняет только демо-ползунки. Перед подключением моторов нужны лимиты осей, проверка wrap-around азимута, концевики, E-STOP и независимая проверка наведения.
- Частоты связи не выводятся из TLE и должны проверяться отдельно по актуальным радиолюбительским/операторским источникам.

## Мобильное приложение

Для Flutter следует использовать тот же контракт данных: объект содержит NORAD ID, имя, эпоху и две строки TLE либо эквивалентный OMM. Рекомендуемая архитектура: `SatelliteCatalogRepository` (HTTP/CelesTrak) → `Sgp4Propagator` → `TopocentricPosition` → общий экран выбора/карточка спутника. Не дублировать в приложении фиксированные AZ/EL значения из демо-каталога.
