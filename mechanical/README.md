# Механика ротатора

AZ: ограниченный поворот с учётом кабельного жгута либо токосъёмное кольцо. EL: диапазон проектируется с механическими упорами и безопасными ограничителями.

Для наружной антенны нужны расчёт ветровой нагрузки, жёсткая металлическая рама, валы и подшипники, редуктор/тормоз и защита от самопроизвольного движения.

Без редукции и проверки момента нельзя считать NEMA17 достаточным для наружной тарелки.
