# Механика ротатора CYD Satellite Tracker

Основная антенна проекта — VHF Crossed Yagi с круговой поляризацией (145 МГц). Ротатор: AZ 360° и EL 0–90°. Два шаговых двигателя NEMA17 (1,5 А по исходным данным проекта), драйверы TMC2209. Масса антенны, ветровая нагрузка и момент двигателей пока не подтверждены.

Подробная документация и иллюстрации: [Механика на GitHub](../docs/mechanics/README.md).

## Краткие требования
- AZ: 360° — кабельный предел или токосъёмное кольцо.
- EL: 0–90° — механические упоры и независимые концевики.
- Центр тяжести антенны располагать как можно ближе к оси EL.
- Проверить момент удержания, ускорение, люфт, резонанс, прогиб и ветровую нагрузку.
- Пластик — PETG/ASA/PA; силовые валы, оси и мачтовые крепления — металлические.
- NEMA17 без редуктора нельзя считать достаточным для наружной антенны до расчёта.
